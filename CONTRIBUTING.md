# Contributing to Imhotep Browser Sync

Thank you for your interest in contributing to **Imhotep Browser Sync**! We welcome community contributions, bug reports, and feature proposals to expand private, zero-knowledge browser synchronization.

---

## 1. Code of Conduct & Values

* **Privacy First**: Any contribution that weakens client-side zero-knowledge encryption or introduces third-party telemetry will be rejected.
* **Lean Architecture**: We prioritize minimal bundle sizes (~60KB popup target), fast startup, and native Web standards over heavy frontend frameworks.
* **Respectful Collaboration**: Maintain inclusive, constructive, and respectful communication in all issues, pull requests, and discussions.

---

## 2. Development Setup

### Prerequisites
* **Node.js**: v18.0.0 or higher
* **npm**: v9.0.0 or higher
* **Supported Browsers for Testing**:
  * Desktop: Helium Browser, Google Chrome, Brave, Microsoft Edge
  * Android: Kiwi Browser, Lemur Browser

### Installation Steps

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/imhotep-tech/imhotep_browser_sync.git
   cd imhotep_browser_sync
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start the Development Build**:
   ```bash
   npm run dev
   ```

4. **Production Build & Packaging**:
   ```bash
   npm run build
   npm run package   # Generates imhotep_browser_sync.zip ready for browser loading
   ```

---

## 3. Loading the Extension Locally

1. Open your Chromium-based browser (Chrome, Helium, Brave, Edge).
2. Navigate to `chrome://extensions/` (or `helium://extensions/`).
3. Enable **Developer mode** in the upper right corner.
4. Click **Load unpacked** and select the `dist/` directory generated by `npm run build`.
5. The Imhotep golden step-pyramid icon should appear in your extensions toolbar.

---

## 4. Architectural Guidelines

Before writing code, please review the domain boundaries:

* `src/crypto/`: Zero-knowledge cryptography only. Use native `crypto.subtle` APIs exclusively. Never export derived keys or store plaintext in unencrypted storage.
* `src/p2p/`: WebRTC DataChannel protocols, STUN traversal, pairing logic (mnemonic phrase & QR generation).
* `src/background/`: Chrome Manifest V3 service worker lifecycle, history listener hooks, micro-batch debounce buffers, and extension management.
* `src/popup/`: Glassmorphic Antigravity UI built with pure TypeScript and Tailwind CSS.
* `public/icons/`: High-resolution vector and raster branding assets.

---

## 5. Coding Standards & Git Hygiene

* **TypeScript**: Strict type checking is enforced. Avoid `any`; use proper interfaces and types in `src/types/`.
* **Commit Conventions**: We use [Conventional Commits](https://www.conventionalcommits.org/):
  * `feat(p2p): add QR code pairing generator`
  * `fix(crypto): enforce 12-byte random IV validation`
  * `docs(readme): add Helium browser setup guide`
  * `perf(worker): debounce history micro-batch flushing`
* **Pull Request Checklist**:
  - [ ] Passes `npm run build` without TypeScript errors.
  - [ ] Does not touch unencrypted telemetry or telemetry endpoints.
  - [ ] Follows existing code formatting and directory layout.
  - [ ] Updates relevant documentation if changing features or protocols.
